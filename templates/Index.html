Frequently Asked Questions

What's the difference between the File Converter and Image Upscaler?

The File Converter changes the format (e.g., HEIC to JPG, or images to PDF) without changing the resolution. The Image Upscaler increases the resolution (e.g., 1080p to 4K), making images larger and sharper.

Are my files safe?

Yes. Files exist in temporary operational memory during processing and are immediately cleared once sent back to your browser. No files are logged or saved to server storage.

Can I process multiple images at once?

Yes. Both tools support batch uploads up to 100 files. If you have 3 or more files, they will download automatically as a single ZIP package.

Does upscaling make my images sharper?

Our upscaler uses Lanczos resampling, the sharpest non-AI algorithm available. It cannot invent new detail that wasn't in the original image, but it produces the cleanest possible result. For AI-based enhancement, a dedicated AI upscaler is required.
