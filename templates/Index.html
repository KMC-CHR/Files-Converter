Frequently Asked Questions

Are my files safe?

Yes. Files exist in temporary operational memory during processing and are immediately cleared once sent back to your browser. No files are logged or saved to server storage.

Can I convert multiple images at once?

Yes. You can add up to 100 images to the processing queue. Converts run sequentially and download automatically as single files or a ZIP package if you have 3 or more files.

Why does the YouTube download take a while?

Our server must fetch the video, extract the audio using FFmpeg, and then send it back to you. This process takes a few seconds depending on the video length and server load.
